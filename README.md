# 일렉트론 레이싱 (Electron Racing)

**일렉트론 레이싱**은 전기 개념을 설명으로 먼저 가르치기보다, 학생이 짧은 인터랙티브 경험을 통해 현상을 직접 경험하고 질문하도록 설계한 과학 학습 콘텐츠입니다.

#### 경험 → 관찰 → 질문 → 힌트 → 개념

게임이 수업을 대신하는 것이 아니라, 교재와 연결되어 과학적 궁금증을 만들어 내는 짧은 경험 장치로 사용됩니다.

## Rounds

### ROUND 1 — 저항

은 → 금 → 구리 도선을 각각 15초씩 경험합니다. 원자 장애물과의 충돌을 통해 움직임을 방해하는 현상을 경험하고, **충돌 횟수 = 저항값(Ω)**으로 연결합니다.

### ROUND 2 — 전압

같은 구리 도선에서 10초간 기본 속도로 이동한 뒤, 10초간 공기 부스터가 자동 적용됩니다.

"일렉트론 레이서를 밀어주는 뭔가가 생겼다.
저 에너지나 압력의 정체가 뭐지?"

경험한 속도 차이를 통해 전압이라는 개념을 호출합니다.

### ROUND 3 — 전류

여러 일렉트론 레이서의 움직임을 통해 전류 개념을 경험하도록 설계했습니다.

세 라운드는 하나의 게임 엔진으로 구성되어 있으며, 각 라운드를 독립적으로 선택할 수 있습니다.

## Educational Design

일렉트론 레이싱은 오래 플레이하게 만드는 게임을 목표로 하지 않습니다.

● 순위 없음

● 레벨 없음

● 성장 시스템 없음

● 짧은 플레이

● 빌런의 질문과 힌트 제공

● 플레이 후 교재로 돌아가 자신의 생각 기록

게임에서 현상을 경험하고, 그 현상을 설명하기 위해 필요한 순간에 과학 개념을 호출합니다.

## Design Principle

실제 전기 현상을 완벽하게 시뮬레이션하기보다, 현재 학습 단계에서 필요한 관계를 이해할 수 있는 이론적 모델을 사용합니다.

중요한 것은 게임이 얼마나 정교한가가 아니라,

**학생이 경험을 통해 "왜?"라는 질문을 갖게 되는가**

입니다.

## Original Project & Acknowledgments

이 프로젝트는 오픈소스 브라우저 레이싱 게임 **Moto Racer**의 구조와 구현을 참고하여 시작했습니다.

이미 해결되어 있는 브라우저 레이싱의 기본 구조를 활용할 수 있었기 때문에, 일렉트론 레이싱에서는 게임 엔진을 처음부터 만드는 대신 교육적 경험의 설계에 집중할 수 있었습니다.

원본 프로젝트의 라이선스 및 저작자 표시는 배포 시 해당 프로젝트의 조건을 따릅니다.

Special thanks to the original creator of **Moto Racer** for making the project available as an open-source HTML5 game.

This project was inspired by its lightweight browser-based racing structure and adapted into **Electron Racing**, an interactive science learning experience.

**Thank you for sharing your work with the open-source community.**
